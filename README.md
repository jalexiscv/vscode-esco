# Paquete de idioma español (Colombia) para VS Code

Este paquete adapta la interfaz de Visual Studio Code al español de Colombia (`es-CO`).

## Uso

1. Instala la extensión.
2. Abre la paleta de comandos con `Ctrl+Mayús+P` y ejecuta **Configure Display Language**.
3. Selecciona **español (Colombia)** y reinicia VS Code.

## Origen

Este proyecto parte de las traducciones al español de
[microsoft/vscode-loc](https://github.com/microsoft/vscode-loc) (versión 1.131.0), publicadas bajo licencia MIT.
Sobre esa base se aplica una adaptación al vocabulario y al uso de Colombia.
