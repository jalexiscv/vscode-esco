# Registro de cambios

## [1.131.0] - 2026-10-15

Primera versión del paquete de idioma español de Colombia, para VS Code 1.131.

- Basado en el paquete español 1.131.0 de microsoft/vscode-loc.
- Adaptado al uso de Colombia en 176 cadenas: archivo, mouse, video, pestaña,
  presionar, teclas Shift/Enter/Tab y tratamiento de usted.
- Traducidas 2,671 cadenas que el paquete base dejó en inglés (chat, agentes,
  sesiones, automatizaciones, autenticación de GitHub, Markdown, entre otras).
- Corregidos vínculos `(comando:…)` que no funcionaban por tener el esquema traducido.
